# 墨境 · UI 设计规范与优化方案 v1

> 基于对 `src/styles.css`（1115 行）与全部页面的代码级审计。
> 目标：不改变「纸墨书房」气质方向，解决执行不一致带来的可读性与维护性问题。

---

## 一、现状审计（问题定位）

### 1.1 字号：最大的可用性问题 🔴

| 字号 | 出现次数 | 占比 | 问题 |
|---|---|---|---|
| 6px | 1 | — | 完全不可读 |
| 7px | 18 | 6% | 完全不可读（marker 标签、pane-title label） |
| 8px | 54 | 19% | 不可读（页面眉标、按钮、chips 几乎全是） |
| 9px | 80 | 29% | 勉强可读（正文小字、列表元信息） |
| 10px | 41 | 15% | 偏小 |
| 11px | 31 | 11% | 中文下限 |
| 12px+ | 60 | 21% | 正常 |

**279 处 font-size 中 54% 在 6-9px**。中文可读下限是 12px（正文 14px）；当前大量功能性文字（按钮、标签、导航）低于 10px，高 DPI 屏幕上需要凑近看。**这是所有 UI 问题里投入产出比最高的一项。**

### 1.2 颜色：753 处硬编码，token 无人使用 🟠

`:root` 已定义 15 个变量（`--paper/--ink/--accent/--sage/--line...`，方向正确），但正文中几乎都是直接写 hex：
- 近似灰阶 ≥ 12 个（`#9a9d98`×13、`#969994`×9、`#a2a39e`×6…视觉相同）
- 近似纸色 ≥ 8 个（`#fffefa`×23、`#f0ede6`、`#ebe8e0`、`#dedbd2`…）
- 页面 TSX 里还有三份独立色表（constants COLORS / TYPE_COLOR / PALETTE）

后果：改一个品牌色要动几十处；暗色模式无从下手。

### 1.3 圆角/间距/阴影不成体系 🟡

- 圆角 183 处，5/6/7/8/9/10/11/13px **八种值并存**
- 间距全是魔法数字（`padding: 0 9px`、`3px 5px`、`8px 17px`…）
- 阴影各处自写

### 1.4 其他 🟡

- 图标按钮 11+ 处缺 `aria-label`/title；Modal 无 Esc 关闭
- `window.alert/confirm` 4 处（与纸墨风格割裂）
- 内联 style 约 40 处（SettingsPage 12 处）

## 二、设计原则（不变的方向，更明确的执行）

1. **纸墨为底，赭石点睛**——纸色大面积、墨色文字、赭石 `#a45d43` 只用于关键动作与选中态，绝不大面积铺。
2. **中文优先的可读性**——正文 14px 起；辅助信息 12px 起；**永远不用 <12px 渲染中文**。
3. **一个层级一个字重**——靠字号+灰阶区分层级，不靠缩字。
4. **留白是纸的味道**——8 的倍数间距体系，宁松勿挤。

## 三、设计 Token 体系 v2

### 3.1 字阶（8 档，替换全部 279 处）

```css
:root {
  --fs-2xs: 10px;  /* 仅装饰性英文眉标 eyebrow（uppercase + letterspacing）*/
  --fs-xs:  12px;  /* 辅助信息：时间戳、计数、chips */
  --fs-sm:  13px;  /* 次要正文：列表元信息、表内小字 */
  --fs-md:  14px;  /* 正文基准：列表主文字、表单、按钮 */
  --fs-lg:  16px;  /* 卡片标题、面板标题 */
  --fs-xl:  19px;  /* 页面标题 */
  --fs-2xl: 24px;  /* 英雄区大标题（Noto Serif SC）*/
  --fs-serif-lg: 15px; /* 衬线正文（章节标题、详情标题）*/
}
```

**映射规则**（全局替换脚本即可完成大半）：
`6/7px→--fs-2xs`、`8px→--fs-xs`、`9/10px→--fs-sm`、`11px→--fs-md`、`12px→--fs-md`、13px 保持、`14px→--fs-md`、15px+ 保持。

### 3.2 色彩（收敛为 24 个语义 token）

```css
:root {
  /* 墨阶（文字）—— 5 档，替代 12 个近似灰 */
  --ink:        #293032;   /* 主文字 */
  --ink-2:      #4a5254;   /* 次要文字 */
  --ink-3:      #7d827f;   /* 辅助/占位（替代 #9a9d98 系）*/
  --ink-4:      #a6a9a4;   /* 禁用/极弱 */
  /* 纸阶（背景）—— 5 档，替代 8 个近似纸色 */
  --paper:      #fffdf8;   /* 卡片/弹层 */
  --paper-2:    #f5f1e8;   /* 页面底 */
  --paper-3:    #ece8de;   /* 分区/侧栏底 */
  --paper-4:    #e2ded4;   /* 悬浮/hover */
  /* 线与投影 */
  --line:       #dedbd2;   /* 边框（统一替代 6 种近似值）*/
  --line-strong:#c8c4b8;
  --shadow-sm:  0 2px 8px rgba(39,43,42,.06);
  --shadow-md:  0 6px 20px rgba(39,43,42,.10);
  --shadow-lg:  0 12px 32px rgba(39,43,42,.14);
  /* 品牌与功能色 */
  --accent:     #a45d43;   /* 赭石：主按钮/选中/链接 */
  --accent-soft:#f3e5df;   /* 选中底 */
  --sage:       #74806b;   /* 苔绿：成功/自然 */
  --blue:       #55768a;   /* 信息 */
  --amber:      #b88446;   /* 提醒 */
  --danger:     #b5493a;   /* 删除/错误（已在使用，纳入体系）*/
  /* 暗色模式预留：全部颜色经语义 token 引用后，暗色只需覆写 token 值 */
}
.dark {
  --ink:#e8e4da; --ink-2:#c4c0b6; --ink-3:#8f8b82; --ink-4:#6b6862;
  --paper:#2b2a27; --paper-2:#232220; --paper-3:#2e2d2a; --paper-4:#383632;
  --line:#3d3b37; --line-strong:#4a4844;
  --accent:#c97b5e; --accent-soft:#4a352d;
}
```

三份 TSX 色表（COLORS/TYPE_COLOR/PALETTE）迁入同一 token 文件 `src/lib/designTokens.ts`，与 CSS 变量同值。

### 3.3 间距（4/8 栅格）

```css
--sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px;
--sp-5: 24px; --sp-6: 32px; --sp-7: 48px;
```

### 3.4 圆角（收敛 8 种→4 档）

```css
--r-sm: 4px;  /* chips、小标签 */
--r-md: 8px;  /* 按钮、输入框 */
--r-lg: 12px; /* 卡片、面板 */
--r-full: 999px; /* 胶囊、圆形 */
```

## 四、全局改进清单

| # | 改进 | 涉及 | 方式 |
|---|---|---|---|
| G1 | **字号全量提升**（6-11px→≥12px） | 279 处 | 正则批量替换到字阶 token + 逐页视觉走查 |
| G2 | 颜色收敛到语义 token | 753 处 hex | 按映射表批量替换（`#9a9d98→--ink-3` 等） |
| G3 | 圆角/间距/阴影 token 化 | ~400 处 | 批量 + 走查 |
| G4 | 替换 4 处 `alert/confirm` 为应用内 Modal/确认条 | 4 文件 | 复用地形删除的红色确认条样式 |
| G5 | 图标按钮补 `aria-label`、Modal 加 Esc | ~15 处 | 逐个补 |

## 五、逐页面要点

| 页面 | 问题 | 改法 |
|---|---|---|
| **写作页** | 稿纸区与侧栏密度失衡；页眉字 8px | 稿纸区加宽呼吸感（padding 32→40）；状态条 12px |
| **概览页** | 指标卡数字与标签对比弱（标签 8px） | 数字 24px 衬线 + 标签 12px，数字成为视觉锚点 |
| **大纲·思维导图** | 节点 7-9px，连线标签不可读 | 节点标题 13px、内容 12px；缩放分级显示 |
| **角色/地点/世界观/伏笔** | 主从布局列表 9px | 列表主文字 14px、元信息 12px；选中态用 `--accent-soft` |
| **地图页** | marker 标签 6-7px；地形面板过密 | marker 标签 ≥11px 加白底描边；面板行高 28→32px |
| **设置页** | 12 处内联样式；分区标题弱 | 内联样式入 class；分区标题 16px 衬线 |
| **项目页** | 封面字过小 | 封面书名 20px 衬线 |

## 六、暗色模式路线（token 化之后）

1. **前提**：G2 完成（所有颜色经 token）——否则暗色是灾难
2. 机制：`html.dark` 类 + `prefers-color-scheme` 自动初始 + 设置页开关（存 localStorage）
3. 特殊处理：稿纸区保持纸色（写作的「纸」不跟随暗色，仅界面 chrome 变暗——写作软件惯例，Scrivener/Ulysses 同款处理）；地图涂鸦色不反转
4. 工作量：token 化后仅 ~40 行覆写 + 开关 UI

## 七、实施路线

```
阶段 1（最高收益，半天）  G1 字号全量提升 + 逐页走查
阶段 2（半天）            G2 颜色收敛 + TSX 三色表合并
阶段 3（2小时）           G3 圆角/间距/阴影 + G4 alert 替换
阶段 4（半天）            G5/G6 a11y 与交互细节 + 逐页要点
阶段 5（可选，半天）      暗色模式（依赖阶段 2）
```

> 阶段 1 单独做完，观感即有质变；阶段 2 是暗色模式的前置。
