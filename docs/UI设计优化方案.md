# 墨境（InkForge）UI 设计优化方案 v1

> 撰写时间：2026-08-19 ｜ 范围：前端视觉与交互（src/styles.css、pages/、components/）
>
> 方法：基于当前代码实况盘点（非截图印象）——所有问题均标注文件位置与量化数据。
>
> 定位：墨境是「本地优先的长篇小说创作工具」。UI 的设计目标应该是：**长时间写作不累眼、资料检索快、状态反馈清晰、有"书房"气质而非"后台系统"气质**。现有 UI 骨架已经不错（暖纸色 + 墨色侧栏的国风视觉方向是对的），问题集中在**系统性缺失**：没有设计 token、字号失控、反馈层缺失、死交互拉低信任感。

## 二、核心诊断（按伤害排序）

### D1【P0·可读性】字号体系失控，大量低于可读下限

7-9px 中文在 100% 缩放屏幕上已低于人眼舒适阅读下限；在高分屏缩放（125%/150%，Windows 笔记本默认）下进一步恶化。**这是全应用最伤体验的问题。**

- 7px：14 处（如 kbd、tag、微标签）
- 8px：51 处（辅助说明、图例、状态字）
- 9px：78 处（**正文级内容也在用**：attention 标题、列表元信息）

**方案**：建立 5 档字号 token，全量替换（见三.2）。最小可用字号定为 **11px**，辅助信息 10px 仅用于确属"注释级"的内容。

### D2【P0·系统性】设计 token 缺失

颜色有变量，字号/间距/圆角/阴影/层级全部硬编码。导致：改一个间距要全文搜索；新组件随手写 8px；视觉无法收敛。

**方案**：扩展 `:root` 为完整 token 体系（三.1），CSS 改写时逐步替换硬编码值。

### D3【P0·离线可用性】远程字体依赖

`@import url('https://fonts.googleapis.com/...')` 在断网时阻塞/回退，且每次启动外联。**本地优先应用不应依赖外网资源。**

**方案**：Noto Serif SC 改本地打包（`dist/assets/fonts/`，woff2 约 2-4MB 子集化后 <1MB）；或退而求其次用系统衬线栈 `"Source Han Serif SC", "SimSun"` 兜底。

### D4【P1·反馈层】状态反馈缺失

- 保存失败仅编辑器工具栏小字变红，无 toast、无重试入口
- AI 生成中无进度感（只有按钮文案变化）
- 删除作品/章节用原生 `confirm()`，与整体视觉割裂且无法展示后果说明
- 版本回滚、路径迁移等长操作无 loading 遮罩

**方案**：新增全局 Toast 组件 + 用现有 `Modal` 替换全部 `confirm()`（见四.5）。

### D5【P1·壳层】窗口控制假按钮

自定义标题栏（frame:false）却不接 IPC，三个窗口按钮是假的；「文件/编辑/视图/帮助」菜单是装饰。

**方案**：A) 接真 IPC（minimize/maximize/close + 菜单精简为「设置/关于」）；或 B) 移除装饰菜单、窗口按钮改用 `titleBarOverlay`。推荐 A，工作量小且完整。

### D6【P2·密度】微字号+高密度的"仪表盘感"

大量 8-9px + 紧凑间距让产品像监控后台。写作用户需要的是"纸张感"：**正文区留白充足，资料区密度可高但字号不低于 10px**。

### D7【P2·一致性】同类组件多套写法

- 卡片圆角：5/6/7/8/9/10px 混用
- 按钮高度：26/28/32/34/36px 混用
- 空状态：`EmptyState` / `EmptyStateWrap` / `panel-empty` / `xx-empty` 四套

**方案**：收敛为 token + 统一空状态组件。

## 三、设计语言规范（目标态）

### 3.1 设计 Token（写入 styles.css `:root`）

```css
:root {
  /* ── 字号：5 档制，禁用 10px 以下 ── */
  --fs-xs:  10px;  /* 注释级：图例、表尾、版权行 */
  --fs-sm:  11px;  /* 辅助信息：元数据、标签、说明 */
  --fs-md:  12px;  /* 正文默认：列表、表单、按钮 */
  --fs-lg:  14px;  /* 强调：面板标题、卡片主文 */
  --fs-xl:  20px;  /* 页面标题 / 数字大屏 */

  /* ── 间距：4pt 基线 ── */
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px;
  --sp-4: 16px; --sp-5: 24px; --sp-6: 32px;

  /* ── 圆角：3 档 ── */
  --r-sm: 6px;   /* 输入框、小按钮、标签 */
  --r-md: 10px;  /* 卡片、面板 */
  --r-lg: 14px;  /* 弹窗 */

  /* ── 控件高度：3 档 ── */
  --h-sm: 28px; --h-md: 32px; --h-lg: 38px;

  /* ── 阴影：2 层 ── */
  --shadow-1: 0 1px 3px rgba(39,43,42,.06);           /* 静态卡片 */
  --shadow-2: 0 12px 32px rgba(39,43,42,.16);         /* 弹层/悬浮 */

  /* ── 过渡 ── */
  --t-fast: .14s ease; --t-mid: .26s cubic-bezier(.4,0,.2,1);

  /* 色彩沿用现有 12 个变量，补充语义色 */
  --ok: #4e7a5e; --warn: #b88446; --danger: #a3483f; --info: #55768a;
}
```

### 3.2 字号迁移映射（D1 的执行表）

| 现值 | 出现次数 | 迁移到 |
|---|---|---|
| 7px / 8px | 65 | `--fs-xs`(10px)；确属注释级的保留 10px，其余升 sm |
| 9px | 78 | `--fs-sm`(11px) |
| 10px | 40 | `--fs-sm`(11px) 或维持 xs（按内容性质） |
| 11px | 31 | `--fs-md`(12px) |
| 12px | 20 | `--fs-md` |
| 13-15px | 19 | `--fs-lg`(14px) |
| 16px+ | 12 | `--fs-xl` 或逐处审定 |

### 3.3 视觉方向（强化既有"书房"气质）

- **纸墨对比**保留：墨色侧栏（`--sidebar`）做导航与沉浸，纸色内容区（`--paper`）承载创作
- 正文区（写作页纸张、章节列表）背景可加极淡纸纹/暖白渐变，增强"稿纸"感
- `--accent`(赭石 #a45d43) 只用于**主操作与当前态**，不再散用于装饰
- 图标统一 lucide 14/16px 两档，线宽视觉一致

## 四、分区优化方案

### 4.1 壳层（TitleBar/Sidebar/StatusBar）

1. 窗口三键接 IPC（D5）：`minimize()`、`isMaximized()` 切换、`close()`；hover 态遵循 Windows 规范（close 红）
2. 装饰菜单改为真实菜单：「设置」「关于」「导出备份」三项即可，或整体移除
3. StatusBar 信息降噪：合并为 `SQLite·本地 · 自动保存 · 12,340 字`，右侧伏笔数点击直达看板（现在不可点）
4. Sidebar 折叠态补 tooltip（已有 title 属性，保留）；当前项指示条从背景色改为左侧 2px accent 线，更安静

### 4.2 概览页（Overview）

1. 三栏第一行在 1280-1400px 宽度下 Token 用量面板会压缩变形 → 给 `usage-card` 设 `min-width: 240px`，不足时换行到第二行（grid 自动流）
2. 周柱状图数值标签（`em`）与热力图图例都是 8-9px → 按 3.2 升档
3. 「需要留意」urgent 卡当前仅换字色，补左侧 3px 警示条 + 浅底（已有，增强对比）
4. metrics 四卡数值用 `--fs-xl` 衬线体，形成视觉锚点

### 4.3 写作页（核心场景，优先级最高）

1. **正文编辑器**：
   - 字号可调（12/14/16px 三档，写入 localStorage），行高 1.9，段后距 1em
   - 纸张最大宽度 720-780px 居中，当前 `editable-paper` 需检查是否受限
   - 章节标题输入与正文的层级对比加强（衬线 + `--fs-lg`）
2. **保存状态**（D4 核心）：
   - 保存失败 → 右下 toast「保存失败 · 重试」，点击重试；连续失败 3 次提示导出备份
   - 自动保存指示从工具栏小字改为 StatusBar 常驻（与"自动保存已启用"合并为动态）
3. **辅助中心（右侧栏）**：
   - 生成中显示流式字数与已用时（`xx 字 · 12s`）
   - 「停止」按钮与错误提示已具备，保持
4. 章节列表：当前章高亮 + 左侧 2px accent；字数列 `--fs-sm`

### 4.4 资料四页（Characters/Locations/World/Threads）

1. master-detail 左栏列表项 10px 元信息 → `--fs-sm`；选中态统一为浅 accent 底 + 左线
2. Threads 看板卡：`thread-card` 的 9px 描述升至 sm；优先级徽标 major 加重（现有色即可）
3. 表单弹窗（CharacterForm 等）：标签 sm、输入 md；错误信息用 `--danger` + 12px，不再 9px
4. 四页空状态统一用 `EmptyStateWrap`（已有），插图位预留

### 4.5 反馈组件（新增，D4）

```
components/Toast.tsx
  toast.success(msg) / toast.error(msg, { action: '重试', onAction })
  右下角堆叠，4s 自动消失，hover 暂停；--shadow-2 + --r-md
替换点：保存失败、导出成功、复制成功、路径迁移结果、AI 连通测试结果
```

确认弹窗：全部原生 `confirm()`（约 8 处：删作品/章节/角色/地点/设定/伏笔/模型/回滚）替换为 `ConfirmModal`——复用现有 `Modal`，danger 主按钮 + 后果说明文案。

### 4.6 加载与骨架

1. 页面级首载：现有"正在打开本地作品"保留，加连接计时（`useConnectingTimer` 已存在）
2. 列表级：Characters/Threads 首载 `<p>读取中…</p>` → 3 行骨架条（灰色块 + 微光动画）
3. 按钮级：`busy` 态已普遍具备，补统一 spinner 图标旋转动画

## 五、动效规范（补反馈，不炫技）

| 场景 | 动效 | 时长 |
|---|---|---|
| 弹窗进出 | 上浮 8px + 淡入 / 淡出 | 0.26s（--t-mid） |
| 下拉/菜单 | 展开 4px 下滑淡入 | 0.14s（--t-fast） |
| 页面切换 | 内容区淡入（不做滑动，写作工具要稳） | 0.18s |
| Toast | 右侧滑入 | 0.2s |
| 柱状图/热力格 | 高度/颜色过渡（部分已有） | 0.3s |
| hover | 仅背景/边框色变，禁止位移缩放（除按钮压下 translateY(0.5px)） | 0.14s |

遵循 `prefers-reduced-motion` 媒体查询整体关闭。

## 六、响应式与无障碍

1. **断点**：现有 760px 单列回退保留；补 1280px 档（概览三栏→两栏，usage-card 换行）
2. **桌面最小宽度**：`min-width: 1024px`（.desktop）保留，但 Electron 窗口 `minWidth: 1100` 已保证
3. **键盘**：
   - 全局 `Ctrl+K` 命令面板（已有入口展示，确认绑定真实）
   - `Esc` 关闭弹窗（Modal 需补 keydown）
   - `Ctrl+S` 手动保存（写作页）
4. **焦点可见**：已有 `:focus-visible` accent 外框 ✅ 保持
5. **对比度**：8-9px 灰字（#969994 on #fffdf8 ≈ 2.8:1）升字号后需达 4.5:1 → 辅助字色统一 `--muted`(#7d827f) 起步

## 七、实施计划

| 阶段 | 内容 | 工作量 | 验收 |
|---|---|---|---|
| **S1 基建**（先做） | token 体系写入；字号全量迁移（3.2 映射表）；本地字体 | 0.5-1 天 | 全库 font-size ≤5 种值且 ≥10px；断网启动字体正常 |
| **S2 反馈层** | Toast + ConfirmModal 替换 confirm()；保存失败重试；骨架屏 | 1 天 | 全应用无原生 alert/confirm；保存失败可一键重试 |
| **S3 壳层修复** | 窗口 IPC + 菜单实装；StatusBar 降噪可点；死按钮处理（导入 TXT 做真或移除） | 0.5 天 | 三键可用；无死交互 |
| **S4 写作页打磨** | 编辑器字号档/行高/纸宽；保存状态重构；生成进度显示 | 1 天 | 三档字号记忆；失败 toast；生成显示字数+耗时 |
| **S5 一致性收敛** | 圆角/按钮高度/空状态统一；动效按五.表补齐 | 1 天 | 圆角 3 档、控件高 3 档、空状态 1 组件 |
| **S6 响应式/无障碍** | 1280 断点；Esc/Ctrl+S；对比度复查 | 0.5 天 | 缩放 150% 无截断；键盘可完成核心流 |

**原则**：S1 是其余阶段的地基（字号 token 不落地，后面每个改动都在加深失控）；每阶段独立可发布、可回滚。
